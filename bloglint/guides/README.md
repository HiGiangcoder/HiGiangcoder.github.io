# BlogLint — Hướng dẫn viết blog (RAG guides)

Thư mục này chứa các tài liệu ngắn gọn, có trích dẫn nguồn uy tín, dùng làm
ngữ cảnh (RAG) khi BlogLint cần giải thích sâu hơn một issue.

## Cách dùng
- Khi hiển thị issue cho người dùng, có thể tra cứu file tương ứng với
  `category` để lấy ví dụ và nguồn tham chiếu.
- Khi train/eval Student, có thể inject guide liên quan vào prompt để tăng
  độ nhất quán.

## Danh mục
- `clarity.md`
- `coherence.md`
- `grammar.md`
- `spelling.md`
- `style.md`
- `punctuation.md`
- `spacing.md`
- `structure.md`
- `references.md`
